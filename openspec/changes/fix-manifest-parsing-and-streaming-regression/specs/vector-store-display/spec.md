# Vector Store Display

## MODIFIED Requirements

### Requirement: Vector Store Overview MUST display correct metadata from wizard-built manifests

The `/api/vector-store-info` endpoint MUST correctly parse both legacy flat manifests and v1.3/v1.4 nested manifests generated by the corpus wizard. The human-readable overview MUST display the vector store name, embedding model ID, chunking parameters, statistics, and build environment (when available).

#### Scenario: User views Vector Store Overview with a v1.4 manifest

Given a manifest.json generated by the corpus wizard with nested structure (corpus_name, embedding_model as object, embeddings.chunk_size, statistics)
When the user clicks "View Overview" in the UI
Then the modal displays the corpus name (not "(unknown)"), the embedding model ID string (not a raw dict), chunking parameters, document/chunk counts, and build environment section

#### Scenario: User views Vector Store Overview with a legacy flat manifest

Given a manifest.json with flat keys (index_name, embedding_model as string, chunk_size at top level, stats)
When the user clicks "View Overview" in the UI
Then the modal displays the same information correctly using the flat field paths
